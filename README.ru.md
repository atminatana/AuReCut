AuReCut — небольшое бесплатное приложение для Android, которое **записывает, обрезает и сохраняет аудио**. Без рекламы, без аккаунтов, без слежки и даже без разрешения на доступ в интернет: всё происходит на вашем устройстве.

Запишите звук с микрофона или откройте готовый файл, выберите нужный фрагмент, при желании выровняйте громкость и сохраните результат в нужном формате.

## Возможности

- **Запись** с микрофона: источник звука (микрофон, «без обработки» — если устройство поддерживает, распознавание речи, голосовая связь), частота дискретизации (16, 22,05, 44,1 или 48 кГц), моно или стерео. Запись продолжается при выключенном экране и когда приложение свёрнуто.
- **Открытие** файлов WAV, FLAC, AAC/M4A, Opus/OGG и MP3 — из приложения или через «Открыть с помощью» в файловом менеджере.
- **Обрезка** двумя маркерами на волновой форме. По умолчанию выбран весь трек.
  - Масштаб щипком, прокрутка перетаскиванием или кнопки масштаба; полоса-обзор показывает, какой участок сейчас на экране.
  - Маркеры двигаются пальцем, а начало, конец и длительность можно ввести точным временем.
  - **Прослушивание выбранного диапазона** перед сохранением.
- **Нормализация** по пиковому уровню (по умолчанию −1 дБFS, значение можно изменить).
- **Сохранение** в WAV, FLAC, AAC (.m4a) или Opus (.ogg). Для AAC и Opus можно выбрать битрейт. Имя файла вы задаёте сами, а папку выбираете в системном диалоге.
- Подтверждение при выходе, если есть несохранённая работа.

### Форматы

| Формат | Открытие | Сохранение | Примечания |
|---|:---:|:---:|---|
| WAV | да | да | 16-бит PCM. Файлы больше 4 ГБ не сохраняются. |
| FLAC | да | да | Без потерь, кодируется самим приложением. |
| AAC / M4A | да | да | 64, 96, 128 (по умолчанию), 192, 256 кбит/с. |
| Opus / OGG | да | да | 24, 32, 64, 96 (по умолчанию), 128, 192 кбит/с. Opus работает только на 8, 12, 16, 24 и 48 кГц, поэтому другие частоты пересчитываются в 48 кГц — приложение сообщает об этом. |
| MP3 | да | нет | Только открытие. MP3-кодировщика в приложении нет. |

Сохранённый файл имеет ту же частоту дискретизации, что запись или исходный файл (кроме случая с Opus, описанного выше). Какие форматы можно открыть и сохранить, зависит ещё и от кодеков вашего устройства: если кодировщика нет, формат просто не предлагается. Файлы с более чем двумя каналами сводятся к первым двум.

## Установка

Скачайте подписанный APK на странице [Releases](../../releases) и откройте его на телефоне. При первой установке Android попросит разрешить установку из этого источника.

Требуется **Android 10 (API 29) или новее**.

## Языки

Английский, русский, испанский, португальский (Бразилия), французский, немецкий, китайский (упрощённый) и японский. Приложение следует языку системы, а для любого другого языка использует английский. На Android 13 и новее язык для одного AuReCut можно задать в системных настройках.

## Конфиденциальность

- Нет разрешения на интернет, нет аналитики, нет рекламы.
- Разрешения: микрофон (для записи), служба переднего плана типа «микрофон» (чтобы запись не прерывалась при заблокированном экране) и уведомления (только чтобы показать уведомление «идёт запись»; без него запись тоже работает).
- Записи и открытые файлы декодируются в закрытый кэш приложения и удаляются при выходе из редактора и при следующем запуске приложения.

## Сборка из исходников

Нужны JDK 17 и Android SDK (платформа 35). Проще всего открыть проект в Android Studio. Из командной строки:

```bash
./gradlew assembleDebug          # app/build/outputs/apk/debug/app-debug.apk
./gradlew testDebugUnitTest      # модульные тесты аудиоядра
./gradlew lintDebug              # проверка Android lint
```

Релизная сборка подписывается, только если параметры подписи заданы в окружении (см. ниже); иначе `assembleRelease` создаёт неподписанный APK.

### Структура проекта

```
app/src/main/java/org/aurecut/app/
  core/    чистый Kotlin: доступ к PCM, ресэмплер, нормализация, пирамида пиков, запись FLAC и WAV, формат времени
  audio/   аудио Android: служба AudioRecord, декодер, кодировщик AAC/Opus, экспорт, проигрывание диапазона
  ui/      экраны на Jetpack Compose: старт, запись, редактор, окно сохранения
  AppViewModel.kt, MainActivity.kt, AuReCutApp.kt
app/src/main/res/values*/strings.xml   переводы
app/src/test/                          тесты JUnit для core/
```

### Добавить или исправить перевод

Скопируйте `app/src/main/res/values/strings.xml` в `values-<язык>/strings.xml`, переведите и добавьте язык в `app/src/main/res/xml/locales_config.xml`. Подстановки (`%1$s`, `%d`) оставляйте как есть. Pull request'ы приветствуются.

## Выпуск версий (для мейнтейнеров)

Всё делает GitHub Actions:

- **CI** (`.github/workflows/ci.yml`) запускает тесты, lint и отладочную сборку при каждом коммите в `main` и при каждом pull request, а отладочный APK сохраняет как артефакт сборки.
- **Release** (`.github/workflows/release.yml`) запускается, когда вы отправляете тег вида `v1.2.3` (или `v1.2.3-rc1` для предварительной версии). Он собирает подписанный APK, проверяет подпись и публикует GitHub Release с автоматическими заметками, APK и его SHA-256. Имя версии — тег без `v`, код версии — `major*10000 + minor*100 + patch`.

Разовая настройка:

1. Создайте хранилище ключей и **надёжно сохраните его** (каждое обновление должно быть подписано тем же ключом):

   ```bash
   keytool -genkeypair -v -keystore release.jks -alias aurecut \
           -keyalg RSA -keysize 4096 -validity 10000
   ```

2. Добавьте четыре секрета репозитория (Settings → Secrets and variables → Actions):

   | Секрет | Значение |
   |---|---|
   | `KEYSTORE_BASE64` | вывод команды `base64 -w0 release.jks` |
   | `KEYSTORE_PASSWORD` | пароль хранилища |
   | `KEY_ALIAS` | `aurecut` (или выбранный вами псевдоним) |
   | `KEY_PASSWORD` | пароль ключа |

3. Выпустите версию:

   ```bash
   git tag v1.0.0
   git push origin v1.0.0
   ```

Никогда не добавляйте хранилище ключей в репозиторий; `.gitignore` уже исключает `*.jks` и `*.keystore`.
